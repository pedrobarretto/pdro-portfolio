# Welcome to Thoughts

This is where I'll share ideas about software, product, and life. The posts here are just markdown files, so adding a new one is as easy as dropping a `.md` file into `content/thoughts`.

## Why this exists

I wanted a calm place to write. No feeds, no distractions—just the ideas.

## How to add a new post

1. Create a new markdown file in `content/thoughts`.
2. Add front matter with `title`, `description`, and `date`.
3. Write your post below the front matter.

```md
---
title: "My new post"
description: "One paragraph summary"
date: "2026-02-10"
tags: ["engineering", "life"]
---

# My new post

Start writing here.
```
